# 0.3.0 原生上下文视图验收 · 2026-09-27

本轮将先前预览正式接入独立 Bundle。用户要求的入口是会话内“对话 / 轨迹 / 上下文”，设置只放压缩参数。日常 profile、Session Bridge 项目和共享宿主源代码均未修改；0.2.1 原包 SHA 保持不变。

## 实现

- `client.tsx` 注册原生 `conversation.view`，order 20；接收宿主提供的准确 Session ID。设置页移除概览与会话选择，保留带修订号的参数保存。
- `inspector.ts` 通过自己的 Typert Remote 调用官方 `sessionQuery.observeSession`。只读不可变截面，finally 释放读租约；查询变化、卸载、切换会话取消旧请求。没有启动 Agent、修改会话或发起额外模型请求。
- `inspector-fold.ts` 复用宿主 canonical `foldSurface` 及已注册的消息投影，正确处理压缩替换与反向 seq 端点。当前有效内容分七类，历史原文单独标记，工具定义完整列举且结构开销纳入合计。
- 内容每页 50 项，标题和来源检索覆盖全部条目；正文按需每段最多 16,000 字符，保护 UTF-16 代理对。超过 50,000 条日志明确拒绝不完整分析。图片仅展示引用，不加载远程图片。
- 最近 200 条回复记录，图中显示最近 40 条，缺失用量显示未知；历史回看是回复完成之后的有效内容，不是那次模型请求原文。压缩记录保持最近 12 条。占用、组成估算、累计消耗分别解释。
- 四个原有 Host 构建文件 `engine/policy/index/diagnostics` 与 0.2.1 字节相同。未改压缩执行器。
